## 7. 角色选择流程说明

### 7.1 关键方法调用链

```
Initialize()                          ← 菜单初始化
  └─ 加载 m_CharacterList (CharaSelectInfo[])
  └─ 按 EnumCharacterID 遍历所有可选角色
  └─ 检查 IsScelectedCharaOpen() → 未解锁角色设置灰度材质 + 占位图

Exec()                                ← 每帧主循环
  └─ Stay(int)                        ← 停留帧处理
  └─ _updateInput()                   ← 输入分发
       └─ _updateInput_Offline()       ← 单机模式
            ├─ _updateInput_PointIndex()   ← 左右移动光标
            │    └─ SetCursorPosition(int)  ← 移动光标到新角色
            │    └─ _updateIndex(int, int)    ← 更新选中索引
            ├─ _updateInput_CharaSelect(int) ← 确认/取消
            │    ├─ _characterSelectEntar(int, bool)  ← 确认选择
            │    │    └─ CharacterSelectEnter(int, EnumCharacterID)  ← 记录选择
            │    │         └─ IsCharacterSelected(EnumCharacterID)  ← 防重复
            │    └─ _CharaSelectCancel(int, bool)   ← 取消选择
            ├─ _updateInput_LifeCount()     ← 调整生命数
            ├─ _updateInput_FriendryFire()  ← 调整友好开火
            └─ _updateInput_GameStart()     ← 按开始键
                 └─ StartGame()
                      └─ OnGameStart(bool)
                           └─ 进入战斗场景（传入选中的 EnumCharacterID）
```

### 7.2 数据读取流程

1. **角色列表初始化**: `Initialize()` 中创建 `CharaSelectInfo[] m_CharacterList`，每个槽位绑定一个 `EnumCharacterID`
2. **角色数据读取**: `_getCharaSelectInfo(EnumCharacterID)` 按 ID 从 `m_CharacterList` 查找对应槽位
3. **属性数据加载**: 运行时通过 `CharaStatus.Set(mstActorParamaterData)` 从数据表加载基础属性，再结合 `mstStatusTableData` 的倍率计算最终值
4. **确认选择**: `CharacterSelectEnter(int playerIndex, EnumCharacterID charaID)` 记录 P1/P2 选择
5. **开始游戏**: `StartGame()` → `OnGameStart(bool)` 将选中的角色 ID 传递给战斗场景

## 8. 隐藏角色解锁机制

### 8.1 Unity 侧解锁机制（已存在）

Unity 原版**已有完整的隐藏角色解锁系统**，挂在以下位置：

| 机制 | 位置 | 说明 |
|---|---|---|
| **解锁状态字段** | `CharaSelectInfo.isOpen` (bool) | 每个角色槽位是否解锁 |
| **解锁检查方法** | `CTenchiCharaSelectMenu.IsScelectedCharaOpen(EnumCharacterID, int)` | 检查指定角色是否已解锁 |
| **解锁值获取** | `CTenchiCharaSelectMenu.get_UseCharacterOpenValue()` | 从存档读取解锁进度 |
| **设置解锁** | `CTenchiCharaSelectMenu.SetPlayerUseCharacterOpen(int, int)` | 设置角色解锁状态 |
| **锁定视觉表现** | `m_SpriteGrayscaleMaterial` + `m_NotOpenSprite` | 未解锁角色显示灰度+占位图 |
| **解锁 UI 标签** | `CharaSelectInfo.openLabelID` (int) | 解锁提示文本 ID |

### 8.2 Godot 侧对应

Godot 侧的隐藏角色（`bosozoku`/暴走族）通过 `character_data.gd` 中的 `hidden: true` 标记 + `unlocked_hidden` 布尔值控制。这是 Unity `isOpen` 字段的简化版。

> **结论**: Unity 原版的解锁机制比 Godot 当前实现更完善——它不仅有布尔值，还有 `openLabelID`（解锁提示文本）、灰度材质、占位图等视觉反馈。移植时建议保留这些视觉元素。

## 核心结论摘要

1. **角色选择菜单**: `NK21.CTenchiCharaSelectMenu`（31 字段/68 方法），通过 `m_CharacterList` (CharaSelectInfo[]) 管理所有可选角色，`_updateInput_CharaSelect()` + `CharacterSelectEnter()` 完成选择确认。

2. **角色数据表**: `NKSP.mstFodd_CharaData`（ScriptableObject 容器）+ `mstFodd_CharaDataData`（数据行），每角色含 **5 个 waza 槽位**（`ewazaid1-5` + `iswaza1-5special`），比 Godot 的单必杀技设计更丰富。

3. **属性倍率**: Unity 侧的 `mstStatusTableData`（`hp_mul`/`speed_mul`/`punch_mul`/`kick_mul`/`weapon_mul`）就是 Godot `hp_mult`/`speed_mult`/`atk_mult` 的原版对应。`jump_mult` 和 `melee_range_mult` 是 Godot 新增维度。

4. **5 角色 ID 映射**: KUNIO=0（飞机头）, SUGATA=1（疾风）, ONIZUKA=6（暴走族）, RIKI=13（格斗）, GOUDA=21（铁壁）。

5. **隐藏角色解锁**: Unity 原版已有完整机制（`CharaSelectInfo.isOpen` + 灰度材质 + 占位图 + 解锁标签），Godot 当前仅用布尔值简化实现。
