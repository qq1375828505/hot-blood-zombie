# 融合方案 01：Godot 枪械+近战武器系统 → Unity 版注入方案

> 目标：将 Godot 项目 hot-blood-zombie 的 **4 枪械 + 3 近战** 武器玩法，翻译为 River City Rival Showdown（Unity/Mono）的 **Harmony 注入方案**。
> 环境约束：只有 dnfile 0.18.0 只读元数据，无 dnSpy/ILSpy/monodis/编译器。产出为方案文档 + C# 参考代码，不实际改 DLL。
> 查询方式：全部类名/字段名/方法名/枚举值均来自 `dnfile` 直接解析 Assembly-CSharp.dll 元数据表。方法内部逻辑不可见，涉及处标注"推断"。

## 一、Godot 武器系统设计摘要

### 1.1 枪械（weapons.gd WEAPONS 表）

| 武器 key | 冷却(s) | 最大弹药 | 伤害 | 子弹速度 | 行为说明 |
|---|---|---|---|---|---|
| `pistol` | 0.25 | -1（无限） | 2 | 640 px/s | 默认副武器，手枪子弹黄色 |
| `machine_gun` | 0.08 | 120 | 2 | 900 px/s | 高射速，子弹青色 |
| `shotgun` | 0.60 | 24 | 1（每颗弹丸） | 560 px/s | 散射，子弹橙色 |
| `grenade` | 1.00 | 3 | 8 | 0（抛物线） | 手雷，落地后 1.5s 引信爆炸 |

### 1.2 近战（weapons.gd MELEE_WEAPONS 表）

| 武器 key | 基础伤害 | 耐久 | 范围倍率 | 击退倍率 | 可格挡 | 名称 |
|---|---|---|---|---|---|---|
| `iron_pipe` | 6 | 15 | 1.5 | 1.5 | false | 铁管 |
| `tire` | 4 | 20 | 1.2 | 2.0 | false | 轮胎 |
| `trash_lid` | 3 | 25 | 1.0 | 1.0 | true | 垃圾桶盖 |

> 近战武器每次命中 -1 耐久；格挡时受击伤害 ×0.5，每次格挡耗 2 耐久；耐久耗尽后武器消失。

### 1.3 子弹行为（bullet.gd）

- 继承 `Area2D`，直线飞行，`dir` 方向 + `speed` 速度
- 生命周期 `life = 2.0s`，超时自动销毁
- 命中任何带 `take_damage` 方法的节点即造成 `damage` 伤害并自毁
- 视觉颜色按武器区分（手枪黄/MG青/霰弹橙）

### 1.4 手雷行为（grenade.gd）

- 继承 `CharacterBody2D`，受重力（`GRAVITY = 980`）
- 投掷初速：X 方向 `THROW_X = 400`，向上 `THROW_UP = 300`
- 落地后启动引信 `FUSE_TIME = 1.5s`，期间闪烁警告
- 爆炸：`BLAST_RADIUS = 80` 范围内所有 `"zombies"` 组节点受 `BLAST_DAMAGE = 8` 伤害
- 视觉：快速放大的橙色色块 + 淡出

### 1.5 拾取逻辑（item_pickup.gd）

- 继承 `Area2D`，碰撞 mask = 1（仅检测玩家）
- 玩家进入触发区 → 发出 `item_picked(item_type)` 信号 → 自毁
- `item_type` 为字符串：`"ammo"` / `"first_aid"` / `"iron_pipe"` / `"tire"` / `"trash_lid"`
- 视觉：不同武器不同颜色色块图标

### 2.7 武器运行时核心类

#### NK21.CItemManager（78 方法）
物品管理器单例。关键字段：
- `m_ItemPrefab` / `m_DropItemPrefab` / `m_BulletItemPrefab` — 三种预制体
- `m_WeaponDataTable` / `m_BulletDataTable` — 武器/子弹数据表
- `m_DropedItemList` / `m_DropedItemList_Weapon` — 场景中掉落物列表
- `m_ItemPool` / `m_DropItemPool` / `m_BulletItemPool` — 对象池
- `baseID_Weapon` — 武器基础 ID

关键方法：
- `CreateItemObject()` / `CreateDropItemObject()` / `CreateBulletItemObject()` — 生成物品
- `GetWeaponData()` / `GetBulletData()` / `GetItemData()` — 查表
- `IsNearItemSearch()` / `IsNearItemsSearch()` — 搜索附近物品
- `SetBulletDelete()` / `SetItemDelete()` — 删除物品
- `WeaponSerialNumber` / `BulletSerialNumber` — 序列号分配

#### NK21.CBulletItemControl（8 方法）

方法：`Awake` / `Initialize` / `FixedUpdateRun` / `SetNextAction` / `ChangeAction`。

> **推断**：子弹是一个带状态机的物品对象，通过 `m_NowBulletAction` / `m_NextBulletAction` 切换飞行/消失等状态。

#### NK21.CPickObjectControl（46 方法）

#### NK21.ItemControl（77 方法）

## 三、注入点映射表

> 每个 Godot 特色玩法 → Unity 对应注入点。
> 注入类型：**新增类**（Harmony mod 程序集里写新类）/ **扩展枚举**（枚举不可运行时扩展，用常量/字典替代）/ **Harmony Prefix/Postfix**（不改 DLL 方法体，在外部 patch）/ **新增数据表行**（运行时往 List 里塞数据）。

| # | Godot 特色 | Unity 对应类/方法/字段 | 注入类型 | 可行性 | 理由 |
|---|---|---|---|---|---|
| 1 | 手枪无限弹药 | `mstWeaponDataData.weaponpower` + 新增 `ammo` 字段概念 | 新增类 `GunWeaponDef`（常量表）+ Postfix `GetWeaponPower()` | **高** | 伤害走已有 `CDamageCalculator.GetWeaponPower()`，只需在 patch 里拦截返回枪械伤害 |
| 2 | MG 高射速 | 无直接对应（原游戏武器攻击走 Animator 事件，无"射速"概念） | 新增类 `GunFireController` + Harmony Postfix 在 `ActorControl.Update` 里做冷却 | **中** | 原游戏攻击节奏由 Animator 驱动，没有 FPS 式射速；需要自己写 Update 冷却逻辑 |
| 3 | 霰弹散射 | `mstAttackCollisionData` 多碰撞体 + `CItemManager.CreateBulletItemObject()` | 新增类 `ShotgunSpread` + Postfix `CreateBulletItemObject` 生成多颗 | **中** | 原游戏已有子弹对象池，散射 = 生成 N 颗子弹，每颗不同方向 |
| 4 | 手雷抛物线 | `EnumItemAction.Item_Throw_Arch` + `CObjectControl.UpdateThrowed()` | Postfix `ThrowObject()` 改用抛物线参数 | **高** | 原游戏已有 `Item_Throw_Arch` 抛物线投掷类型，手雷就是一个特殊投掷物 |
| 5 | 手雷 AOE 爆炸 | `EnumEffect.Explosion_Fire` / `Explosion_Light` + 新增 AOE 伤害逻辑 | 新增类 `GrenadeExplosion` + Postfix 在手雷落地时触发 | **中** | 原游戏爆炸特效已有，但 AOE 范围伤害逻辑需自己写（遍历范围内 actor 调 `CalcDealtDamage`） |
| 6 | 子弹直线飞行 | `CBulletItemControl` + `CObjectControl.m_Velocity` | Postfix `CBulletItemControl.FixedUpdateRun` 覆盖直线运动 | **高** | 原游戏已有子弹状态机，只需让枪械子弹走直线、不反弹 |
| 7 | 子弹生命周期 | `CBulletItemControl.m_VanishFrame` | 字段已有，Postfix 设置 | **高** | 直接用现有 VanishFrame |
| 8 | 子弹命中伤害 | `CDamageCalculator.CalcDealtDamage()` | Postfix 在子弹碰撞时调用 | **高** | 伤害计算管线现成，传入攻击数据即可 |
| 9 | 近战武器耐久 | 原游戏无耐久概念（武器用坏才消失） | 新增类 `MeleeDurabilityTracker`（外部字典跟踪） | **中** | 需在 `SWeaponAttack` 命中事件 Postfix 里扣耐久，耗尽调 `ReleasePickObject()` |

### 4.1 枪械武器类：子弹飞行 + 射速 + 弹药

> 对应 Godot `bullet.gd`。Unity 版已有 `CBulletItemControl`，这里用 Postfix 扩展它。

```csharp
using System.Collections.Generic;
using HarmonyLib;
using NK21;
using UnityEngine;

namespace HotBloodZombieMod
{
    /// <summary>
    /// 枪械开火控制器：挂在 ActorControl 上，管理冷却/弹药/生成子弹。
    /// 对应 Godot player.gd 里的开火逻辑。
    /// </summary>
    public class GunFireController : MonoBehaviour
    {
        public int currentWeaponId = NewWeaponID.NONE;
        public int currentAmmo = 0;
        private float _cooldownTimer = 0f;
        private ActorControl _actor;

        void Awake() { _actor = GetComponent<ActorControl>(); }

        void Update()
        {
            if (_cooldownTimer > 0f) _cooldownTimer -= Time.deltaTime;
            var def = WeaponRegistry.Get(currentWeaponId);
            if (def == null) return;

            // 推断：原游戏用 CInputControl.IsPressKey 检测按键
            // 这里用一个简化的开火输入 hook（实际需接 EnumKeyID）
            bool firePressed = Input.GetKeyDown(KeyCode.J); // 示例键位
            if (firePressed && _cooldownTimer <= 0f)
            {
                Fire(def);
            }
        }

        void Fire(WeaponDef def)
        {
            if (def.kind == WeaponKind.Grenade)
            {
                ThrowGrenade(def);
                return;
            }

            if (def.maxAmmo > 0 && currentAmmo <= 0) return; // 弹药耗尽

            _cooldownTimer = def.cooldown;
            if (def.maxAmmo > 0) currentAmmo--;

            switch (def.kind)
            {
                case WeaponKind.Pistol:
                    SpawnBullet(def, 0f); // 直线
                    break;
                case WeaponKind.MachineGun:
                    SpawnBullet(def, 0f);
                    break;
                case WeaponKind.Shotgun:
                    // 霰弹：5 颗散射（对应 Godot shotgun damage=1 每颗弹丸）
                    for (int i = -2; i <= 2; i++)
                        SpawnBullet(def, i * 8f); // 每颗偏差 8 度
                    break;
            }
        }

        /// <summary>
        /// 生成一颗子弹。调用原游戏 CItemManager.CreateBulletItemObject。
        /// 注意：CItemManager 无静态 Instance（dnfile 验证），是 MonoBehaviour。
        /// 推断：通过 FindObjectOfType<CItemManager>() 或场景单例访问。
        /// </summary>
        void SpawnBullet(WeaponDef def, float angleOffsetDeg)
        {
            // 推断：CItemManager 是场景中的 MonoBehaviour，无静态 Instance
            // 用 FindObjectOfType 获取（实际项目中可能有更好的单例访问方式）
            var itemManager = UnityEngine.Object.FindObjectOfType<CItemManager>();
            if (itemManager == null) return;

            // 推断：角色朝向通过 CObjectControl.m_Flip 获取（dnfile 验证 CObjectControl 有 m_Flip/m_FlipY）
            var objCtrl = _actor.GetComponent<CObjectControl>();
            Vector2 dir = (objCtrl != null && objCtrl.m_Flip) ? Vector2.left : Vector2.right;
            // 应用角度偏移
            float angle = Mathf.Atan2(dir.y, dir.x) + angleOffsetDeg * Mathf.Deg2Rad;
            Vector2 vel = new Vector2(Mathf.Cos(angle), Mathf.Sin(angle)) * def.bulletSpeed;

            // 推断：CreateBulletItemObject 需要位置/方向/伤害参数
            // 实际参数签名需用 dnfile 读 MethodDef Signature blob 确认
            itemManager.CreateBulletItemObject(); // 占位，具体参数需补
        }

        void ThrowGrenade(WeaponDef def)
        {
            // 手雷走投掷管线：CPickObjectControl.ThrowObject
            // 对应 Godot grenade.gd 的抛物线
            var pickCtrl = _actor.m_PickObjectControl;
            pickCtrl.ThrowObject(); // 推断调用现有投掷
        }
    }

    /// <summary>
    /// Postfix：CBulletItemControl.FixedUpdateRun —— 让枪械子弹走直线、不反弹。
    /// 对应 Godot bullet.gd 的 _physics_process：直线飞行 + 生命周期。
    /// </summary>
    [HarmonyPatch(typeof(CBulletItemControl), "FixedUpdateRun")]
    static class BulletStraightPatch
    {
        static void Postfix(CBulletItemControl __instance)
        {
            // 推断：原游戏子弹可能有反弹/重力逻辑。
            // 枪械子弹应走直线、受自身速度控制、不反弹。
            // 通过 m_NowBulletAction 判断是否为"飞行中"状态。
            // 这里仅作示意，实际需读 m_NowBulletAction 的枚举值。
            var objCtrl = __instance.GetComponent<CObjectControl>();
            if (objCtrl != null)
            {
                // 保持直线：不施加重力，速度方向不变
                objCtrl.m_Gravity = 0f; // 推断字段
            }
        }
    }
}
```

### 4.2 手雷类：抛物线 + 爆炸 AOE

> 对应 Godot `grenade.gd`。Unity 版已有 `Item_Throw_Arch` 抛物线类型和 `Explosion_Fire` 特效。

```csharp
using System.Collections.Generic;
using HarmonyLib;
using NK21;
using UnityEngine;

namespace HotBloodZombieMod
{
    /// <summary>
    /// 手雷爆炸器：挂在手雷物品对象上，落地引信倒计时，到期 AOE 伤害。
    /// 对应 Godot grenade.gd。
    /// </summary>
    public class GrenadeExplosion : MonoBehaviour
    {
        public float fuseTime = 1.5f;
        public float blastRadius = 80f;
        public int blastDamage = 8;
        public float gravity = 980f;

        private float _fuseTimer = 0f;
        private bool _fuseStarted = false;
        private bool _exploded = false;

        void FixedUpdate()
        {
            if (_exploded) return;

            // 未落地：抛物线运动（对应 Godot 的 velocity.y += GRAVITY*delta）
            if (!_fuseStarted)
            {
                // 推断：用 CObjectControl 的重力/速度
                var objCtrl = GetComponent<CObjectControl>();
                if (objCtrl != null && !IsGrounded(objCtrl))
                {
                    objCtrl.m_Gravity = gravity; // 推断字段
                }
                else
                {
                    _fuseStarted = true;
                    _fuseTimer = fuseTime;
                }
            }
            else
            {
                _fuseTimer -= Time.fixedDeltaTime;
                // 闪烁警告（视觉，用 SpriteRenderer 控制）
                var sr = GetComponent<SpriteRenderer>();
                if (sr != null)
                    sr.enabled = Mathf.PingPong(Time.time * 5f, 1f) > 0.5f;

                if (_fuseTimer <= 0f) Explode();
            }
        }

        bool IsGrounded(CObjectControl ctrl)
        {
            // 推断：用 GroundChecker 或碰撞检测判断落地
            // 简化：检查 m_MoveGround 字段（推断）
            return ctrl.m_MoveGround; // 推断
        }

        void Explode()
        {
            if (_exploded) return;
            _exploded = true;

            // 1. 播放爆炸特效（对应 Godot 的 Tween 放大色块）
            // 推断：游戏内有特效播放接口，EnumEffect.Explosion_Fire
            PlayExplosionEffect(transform.position);

            // 2. AOE 伤害：遍历范围内所有 actor（对应 Godot 的 zombies 组）
            // 推断：CSceneCharaActionView 或 CActorManager 管理所有角色
            var hitColliders = Physics2D.OverlapCircleAll(transform.position, blastRadius);
            foreach (var col in hitColliders)
            {
                var actor = col.GetComponent<ActorControl>();
                if (actor != null)
                {
                    // 走原游戏伤害计算管线：CDamageCalculator.CalcDealtDamage
                    var dmgCalc = CDamageCalculator.get_Instance();
                    // 推断：需要传入攻击者/防守者/攻击数据
                    // CalcDealtDamage 的具体参数签名需用 dnfile 读 MethodDef Signature
                    // dmgCalc.CalcDealtDamage(...);
                }
            }

            Destroy(gameObject);
        }

        void PlayExplosionEffect(Vector3 pos)
        {
            // 推断：游戏有特效播放管理器，EnumEffect.Explosion_Fire / Explosion_Light
            // 这里用占位，实际调用游戏内特效系统
            Debug.Log($"[Grenade] 爆炸特效 at {pos}");
        }
    }

    /// <summary>
    /// Postfix：CPickObjectControl.ThrowObject —— 手雷投掷时附加 GrenadeExplosion 组件。
    /// </summary>
    [HarmonyPatch(typeof(CPickObjectControl), "ThrowObject")]
    static class GrenadeThrowPatch
    {
        static void Postfix(CPickObjectControl __instance)
        {
            // 推断：m_ItemType / m_PickObject 判断是否为手雷
            // 如果是手雷，在投掷出去的物品对象上挂 GrenadeExplosion
            var itemCtrl = __instance.m_ItemControl;
            if (itemCtrl == null) return;

            // 推断：m_ItemType 是 EnumItemType，我们用自定义 ID 标记
            // 实际需通过反射或扩展方法判断
            int weaponId = (int)itemCtrl.m_ItemType; // 推断转换
            if (weaponId == NewWeaponID.GRENADE)
            {
                var grenade = itemCtrl.gameObject.AddComponent<GrenadeExplosion>();
                grenade.fuseTime = 1.5f;
                grenade.blastRadius = 80f;
                grenade.blastDamage = 8;
            }
        }
    }
}
```

### 4.3 武器拾取/切换 Patch

> 对应 Godot `item_pickup.gd`。原游戏已有完整拾取管线，只需让新武器 ID 通过检测。

```csharp
using System.Collections.Generic;
using HarmonyLib;
using NK21;

namespace HotBloodZombieMod
{
    /// <summary>
    /// Postfix：CPickObjectControl.IsPickupWeaponSearch —— 让新武器 ID 也能被拾取检测到。
    /// 对应 Godot item_pickup.gd 的 body_entered 检测。
    /// </summary>
    [HarmonyPatch(typeof(CPickObjectControl), "IsPickupWeaponSearch")]
    static class PickupWeaponPatch
    {
        static void Postfix(CPickObjectControl __instance, ref bool __result)
        {
            // 推断：原方法检测附近是否有可拾取武器。
            // 如果新武器 ID 没被原检测覆盖，这里强制返回 true。
            // 实际需遍历 m_DropedItemList_Weapon 判断物品类型。
            // 这里简化：只要场景中有我们的新武器物品，就允许拾取。
            // 推断：CItemManager 是 MonoBehaviour，用 FindObjectOfType 获取
            var itemManager = UnityEngine.Object.FindObjectOfType<CItemManager>();
            if (itemManager == null) return;
            var weaponList = itemManager.m_DropedItemList_Weapon; // dnfile 验证字段存在
            foreach (var item in weaponList)

                // 推断：item 有 m_ItemType 字段

                    __result = true;

            // 创建后设置武器物品的视觉/数据
            // 推断：刚创建的物品挂在 m_PickObjectControl.m_PickObject 上

    /// Postfix：CPickObjectControl.PickItemObject —— 拾取武器时初始化弹药/耐久。

    static class PickItemInitPatch
    {
        static void Postfix(CPickObjectControl __instance)
        {

            if (actor == null) return;

            // 推断：拾取后 actor 持有武器，读取武器 ID

            var itemCtrl = __instance.m_ItemControl;

            }
        }
```

### 4.4 伤害计算 Patch

> 对应 Godot 子弹命中调 `take_damage`。Unity 走 `CDamageCalculator`。

```csharp
using HarmonyLib;
using NK21;

namespace HotBloodZombieMod
{
    /// <summary>
    /// Postfix：CDamageCalculator.GetWeaponPower —— 枪械武器返回自定义伤害值。
    /// 对应 Godot weapons.gd 里的 damage 字段。
    /// </summary>
    [HarmonyPatch(typeof(CDamageCalculator), "GetWeaponPower")]
    static class GetWeaponPowerPatch
    {
        static void Postfix(CDamageCalculator __instance, ref int __result)
        {
            // 推断：GetWeaponPower 内部根据当前武器查表。
            // 我们拦截：如果当前武器是新增枪械，返回自定义 damage。
            // 实际需知道"当前武器 ID"如何获取（推断从 ActorControl.m_PickObjectControl 读取）。
            // 这里用占位逻辑。
            int currentWeaponId = WeaponHeldTracker.CurrentWeaponId; // 推断外部跟踪
            var def = WeaponRegistry.Get(currentWeaponId);
            if (def != null)
            {
                __result = def.damage; // 枪械伤害覆盖
            }
        }
    }

    /// <summary>
    /// 近战耐久跟踪器：每次武器命中扣耐久，耗尽自动释放。
    /// 对应 Godot MELEE_WEAPONS 的 durability 字段。
    /// </summary>
    public class MeleeDurabilityTracker : MonoBehaviour
    {
        public int weaponId;
        public int maxDurability;
        public int currentDurability;

        public void Initialize(int id, int durability)
        {
            weaponId = id;
            maxDurability = durability;
            currentDurability = durability;
        }

        /// <summary>
        /// 被攻击命中事件 Postfix 调用。
        /// 对应 Godot 的"每次命中 -1 耐久"。
        /// </summary>
        public void OnHit()
        {
            if (maxDurability < 0) return; // 无限耐久
            currentDurability--;
            if (currentDurability <= 0)
            {
                BreakWeapon();
            }
        }

        /// <summary>
```

## 六、风险与注意事项

### 6.1 高风险（必须额外资源/实验）

| # | 风险 | 说明 |
|---|---|---|
| 1 | **子弹预制体缺失** | `CItemManager.m_BulletItemPrefab` 指向游戏自带子弹预制体（对应 Makoto/必杀技子弹）。枪械需要新的子弹预制体（Sprite + Collider + Rigidbody）。**没有美术资源无法做出可视子弹**。最简方案：复用游戏现有子弹预制体，改颜色/速度。 |
| 2 | **Animator 状态机不支持"射击"动作** | 原游戏 839 个动作状态里没有"持枪站立/射击"动画。枪械武器只能复用 `SWeapon_Stand` + `SWeaponAttack_Stand`，视觉上是"拿着日用品挥"。**要真持枪射击需要新动画，工作量巨大**。 |
| 3 | **枚举传入非法值** | `mstWeaponDataData.eenumweaponitem` 类型是 `EnumWeaponItem`，传入 100 等不在枚举定义里的值。C# 枚举底层是 int，运行时不会抛异常，但游戏内查表（如 `Enum.IsDefined`）可能过滤掉。**需测试原游戏是否用 `Enum.IsDefined` 校验**。 |
| 4 | **方法签名未知** | `CItemManager.CreateBulletItemObject()`、`CPickObjectControl.ThrowObject()` 等方法的**参数签名**未从 dnfile Signature blob 解析。上面代码里的调用是推断。**实际 patch 时需用 dnfile 解析 MethodDef.Signature 拿到精确参数列表**。 |

### 6.2 中风险（可行但需调试）

| # | 风险 | 说明 |
|---|---|---|
| 5 | **伤害计算管线参数** | `CDamageCalculator.CalcDealtDamage()` 的参数（攻击者/防守者/攻击数据/伤害类型）未确认。需解析 Signature blob。 |
| 6 | **特效播放接口** | `EnumEffect.Explosion_Fire` 是特效 ID，但**如何播放特效**的接口类/方法未在本次查询中定位。需进一步搜索含 "Effect" 的播放类。 |
| 7 | **弹药 UI** | 原游戏无弹药概念，需自己写 IMGUI 或接入现有 HUD。复杂度中等。 |
| 8 | **近战耐久耗尽的自动丢弃** | `ReleasePickObject()` 的调用时机和参数需测试。 |

### 6.3 低风险（可直接实施）

| # | 事项 | 说明 |
|---|---|---|
| 9 | 武器数值表 | `WeaponRegistry` 字典是纯 C#，无引擎依赖，可直接用。 |
| 10 | 近战伤害覆盖 | `GetWeaponPower()` Postfix 拦截，逻辑简单。 |

| 12 | 手雷 AOE 遍历 | `Physics2D.OverlapCircleAll` 是 Unity 原生 API，可直接用。 |

### 6.4 建议实施顺序

1. **先做近战武器扩展**（铁管/轮胎/垃圾桶盖）：复用原版 `SWeapon_*` 动作 + 数据表加行，风险最低。
2. **再做手雷**：复用 `Item_Throw_Arch` 抛物线 + `Explosion_Fire` 特效 + AOE 遍历。
3. **最后做枪械**：依赖子弹预制体和射击动画，复杂度最高。先用现有子弹预制体改颜色跑通，再逐步替换。
