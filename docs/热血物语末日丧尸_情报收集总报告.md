## 1. UI / 界面设计（最高优先）

### 1.1 热血系列 UI 关键事实

**血条/体力槽**
- **【事实】** 热血物语（FC）：画面顶部横贯显示区，体力槽与金钱共享同一顶部位置，用 SELECT 键切换显示。状态数值为五维：Defense/Strength/Will Power/Stamina/Max Power，初始值 15/63、15/63、15/63、63/127、63/127。Stamina 归零若 Will Power 不足则损失一半金钱并被送回上一个藏身处。
  - 来源：http://shrines.rpgclassics.com/nes/rcr/images/booklet/river_city_ransom.pdf ；https://setsumei.cloudfree.jp/famicom/nekketsumonogatari/nekketsumonogatari.html
- **【事实】** 热血物语 SP（重制版）：顶部扩展为完整状态条，含玩家头像、时刻、区域图标、经验值槽、等级、HP 槽、SP 槽。SP 槽（气力量）通过攻击/被攻击/防御积攒，用于必杀技和"热血计数器"。
  - 来源：https://www.kuniokun.jp/nekketsusp/assets/pdf/nekketsusp_manual.pdf

**商店/菜单系统（热血物语重点）**
- **【事实】** 两层菜单结构：进入商店先显示 Main Menu（分类菜单），选某类后显示具体商品列表与价格。按 B 键返回上层。商店分三类：仅外带、仅堂食、均可。堂食即时回血，外带需手动使用。食物类回血（やきざかな 10 元回 10、にもの 22 元回 18、めしとしる 45 元回 35）；书籍/道具永久提升数值。
  - 来源：http://shrines.rpgclassics.com/nes/rcr/images/booklet/river_city_ransom.pdf ；https://w.atwiki.jp/aniwotawiki/pages/61166.html
- **【事实】** River City Girls（现代重制）：商店列表框设计会变化，画面中央显示当前选中技能的动画预览；购买技能后顶部状态栏追加新能量槽；整体 UI 包装为手机界面，每个角色手机外观不同、贴合性格。
  - 来源：https://takaitashiki.hatenablog.com/entry/2020/05/21/190000

**对话框/角色选择**
- **【事实】** 热血物语对话以角色头顶气泡/文字框呈现，台词简短（"BARF!"）。按 START 暂停后底部消息区切换为命令菜单（物品/文字速度/难度/状态/密码/帮助）。字体为粗体方块像素字体，被复刻为"Artos Sans"。
  - 来源：http://shrines.rpgclassics.com/nes/rcr/images/booklet/river_city_ransom.pdf
- **【事实】** 热血格斗传说故事模式：输入姓名/生日/血型 → 从固定 16 人中选 CPU 搭档 → 确认数值（不同生日/血型组合生成不同属性）。战斗模式支持 2–8 人混战。
  - 来源：https://cf355421.cloudfree.jp/nkakutou/n01_story1.html

**整体视觉语言**
- **【事实】** FC 时代为 8×8 像素点阵粗体字，高饱和硬边色块无渐变，像素化硬边矩形边框无圆角。
  - 来源：https://learnui.qiaomu.ai/styles/pixel-art/

### 1.2 合金弹头 UI 关键事实

**HUD 元素（SNK 官方 Anthology 说明书逐项定义）**

| # | 元素 | 说明 |
|---|------|------|
| 1 | Character Panel | 当前角色头像 |
| 2 | Slug Gauge | 载具生命值；MS4 中兼作连击倒计时 |
| 3 | Explosives Stock | 剩余手榴弹/护盾数 |
| 4 | Ammo Stock | 剩余弹药；手枪显示 ∞ |
| 5 | Hostage Count | 已解救俘虏（POW）数 |
| 6 | Weapons Powerup | 拾取道具切换武器 |
| 7 | Time | 关卡剩余时间 |
| 8 | Score | 当前关卡得分 |
| 9 | Medals | 勋章数（仅 MS4） |
| 10 | Remaining Credits | 剩余续关次数 |

- **【事实】** 屏幕布局：残机数/分数在屏幕上方；左下角为当前武器弹药 + 手榴弹数（双数字并排）；俘虏计数器死亡后归零重置。
  - 来源：https://usermanual.wiki/Document/MetalSlugAnthologyWiiManual.2942809043.pdf ；http://the.metal.slug.free.fr/tutorial.php

**武器切换 UI 反馈**
- **【事实】** 拾取特殊武器时男声旁白大声喊出武器名——"Heavy Machine Gun!"、"Rocket Launcher!"、"Flame Shot!"、"Shotgun!"。这是系列最具辨识度的 UI 反馈之一，纯音频但构成完整的"武器获取确认"体验。HMG 基础弹药 200 发。
  - 来源：https://gamesurge.com/strategies/Arcade/Walkthroughs-M/Metal-slug.shtml ；https://citygame.com.ar/metal-slug-effect-sound/

**载具乘坐时 UI 变化**
- **【事实】** 乘坐时新增 Slug Gauge（载具耐久条），受击减少，归零后载具爆炸。弹药显示从 ∞ 变为实际数字。
  - 来源：https://usermanual.wiki/Document/MetalSlugAnthologyWiiManual.2942809043.pdf

**关卡结算（MISSION CLEAR）**
- **【事实】** BOSS 击败后进入结算。每个自上次死亡以来解救的俘虏 = 10,000 分；超过 10 个额外奖励 100,000 分。死亡后该关俘虏计数清零。结算画面逐一列出本关解救俘虏名字与排名。Stage Clear 音乐"Carry Out"约 8–10 秒，Result Screen 音乐"The Result Is All"约 39 秒。
  - 来源：http://the.metal.slug.free.fr/tutorial.php ；https://vgmdb.net/album/1113

**整体视觉语言**
- **【事实】** 由 Nazca Corporation 设计的专属像素字体，FontStruct 上有社区复刻版。军事风像素化硬边，数字使用等宽像素字体保证分数滚动对齐。
  - 来源：https://www.fontstruct.com/gallery/tag/35103/nazca

### 1.3 现代 2.5D 横版游戏 UI 趋势

**极简 HUD**
- **【事实】** Hotline Miami：HUD 极简到近乎不存在——右上角分数 + 左下角弹药数。无弹药时显示"NO AMMO"。击杀后根据方式弹出不同分数，短暂显示后消失。
  - 来源：https://kcimgdadilhassanwordpress.wordpress.com/2017/06/12/fmp-2d-game-full-game-research-hotline-miami/
- **【事实】** Hollow Knight：生命值 = 左上角一排白色面具（初始 5 个），无敌人血条（BOSS 也不显示），法力为面具下方圆形球体。设计理念：极简 UI 服务于暗黑氛围。
  - 来源：https://www.pierreboussin.com/_files/ugd/b6ab9f_1df054523a5141e094e2606194643ad6.pdf
- **【事实】** Dead Cells：UI 以清晰度为核心。三属性颜色体系（Brutality 红/Tactic 紫/Survival 绿）覆盖 HUD、菜单、图标、武器。HUD 尺寸可调、边框颜色可改。击杀连击图标随进度变化。
  - 来源：https://dead-cells.com/patchnotes/29

**复古韵味保留手法（综合多个像素 UI 设计指南）**
1. 锁定调色板（8–16 色上限，不越界）
2. 统一像素网格（全部 UI 组件用同一像素尺寸，16×16 和 32×32 图标混用会破坏"像素错觉"）
3. 关闭抗锯齿（导出时禁用平滑，保持硬边锯齿）
4. 高饱和硬边色块（不用柔和渐变）
5. 等宽像素字体（数字用等宽字体保证分数滚动不抖动）
6. CRT 效果作为氛围工具（扫描线、色差、磷光余辉）
7. 微交互反馈（拾取时高音 + 分数闪烁 100ms + 弹出动画）
8. 8px 网格对齐
- 来源：https://image-to-pixel-art.com/pixel-art-for-indie-game-ui ；https://www.zapcode.dev/learn/pixel-art-games-with-ui-ux-design

### 1.4 对《热血物语：末日丧尸》UI 设计的建议

**建议 1：融合式 HUD 布局——"热血顶栏 + 合金弹头左下角弹药"**
- 屏幕顶部：得分、残机（不良少年人数）、剩余时间（沿用合金弹头顶部信息带）
- 屏幕左下角：当前武器弹药数 + 手雷数（双数字并排），拾取武器时配合热血系旁白式语音（如"おらあ！ショットガンだ！"）
- 屏幕左上角：主角体力槽——红色热血色横条 + 数字，低血量时红色闪烁
- 屏幕右上角：金钱/热血点数显示

**建议 2：离散"不良少年头像"式生命条**
- 主角生命值用一排不良少年头像图标（5–7 个），受击变暗/破碎，回复道具（饭团、泡面、运动饮料）恢复——既保留热血系"街头零食"幽默感，又符合现代离散资源 UI 趋势
- 丧尸 BOSS 血条用横贯屏幕底部的粗红条（现代做法是给 BOSS 加血条，Hollow Knight 因无 BOSS 血条被诟病）

**建议 3：商店系统——两层菜单 + 中央预览动画**
- 黑市/武器店采用两层菜单：左列分类（武器/防具/零食/技能书），右列商品列表+价格
- 选中商品时画面中央弹出该武器的像素动画预览（参考 River City Girls），购买后顶部状态栏追加新武器图标

**建议 4："热血魂"SP 槽 + 充能反馈**
- 通过击杀丧尸、受击、连击积攒；满槽时释放必杀（"热血百裂拳""飞车踢"）
- 充能反馈：槽体颜色从灰 → 黄 → 红渐变，满槽时闪烁 + 屏幕边缘泛红光

**建议 5：视觉语言——像素硬边 + 高饱和热血配色 + 等宽数字**
- 调色板：热血红（#E63946 类）、热血蓝（#1D3557 类）、热血黄（#FFB703 类）为主色，丧尸绿（#80B918 类）为辅助色——锁定 12–16 色
- 字体：标题/菜单用粗体方块像素字，数字/分数用等宽像素字体
- 边框：全部 UI 用像素硬边矩形，无圆角、无渐变、无抗锯齿

## 2. 系统与玩法

### 2.1 热血系列战斗与玩法系统

**基础战斗操作骨架**
- **【事实】** A＝拳、B＝脚、A+B＝跳、方向键连按两次＝冲刺；派生"跳踢""冲刺拳"。可拾取场景小物当武器（铁链、木刀、石子、指虎、轮胎等），既能打也能扔。**手持武器期间无法防御**——高威力长手 vs 失去格挡，是核心风险/收益设计。
  - 来源：https://setsumei.cloudfree.jp/famicom/nekketsumonogatari/nekketsumonogatari.html ；https://w.atwiki.jp/gcmatome/pages/5730.html

**根性/不倒地系统（系列招牌手感）**
- **【事实】** 热血物语特有"気力（きりょく）"：体力归零倒地后，若気力 ≥32，会把一部分気力还原成体力直接站起不死；起身有延迟、喘气动作，营造"打残了还硬撑"的热血感。公开数值：ぼうぎょ＝15–63、きりょく＝15–63、たいりょく＝63–127。
  - 来源：https://sho1go.com/fc-010/ ；https://w.atwiki.jp/aniwotawiki/pages/61166.html

**必杀技系统（四类触发机制）**
- **【事实】① 买书习得型（热血物语）**：在书店买"必杀技之书"永久学会——まっはぱんち（马赫拳）约 3000 円、まっはきっく（马赫踢）约 3000 円、すとんぴんぐ（踩踏）约 4000 円、"人間魚雷"约 8000 円（社区评价其实用性低，是"贵≠强"的反例）。
  - 来源：https://studiopoppo.jp/poppoblog/game-play/8230/
- **【事实】② 等级习得＋気力消耗型（初代热血硬派 RPG 化分支）**：必杀随等级习得，释放消耗気力（SP）。典型：ぶんなぐる Lv28/消费30（攻+50）、こんじょう Lv30/消费45（回血35–45）、みきる Lv33/消费45（守备+127）、ぶっとばす Lv35/消费100（攻+127）。気力在不攻击时随时间缓慢回复。
  - 来源：https://asobigokoro.work/Game-strategy-site/the-original-nekketsu-koha-kunio-kun-list-of-ki-powered-moves/
- **【事实】③ 装备选择型（热血时代剧）**：全系列共 25 种必杀技，但按角色定位精选装备自己的配招，做 build。
  - 来源：https://sollkanon.com/game/zidaigeki/hissatsu.html
- **【事实】④ 能量槽/热血槽型（近作与体育作）**：超热血高校躲避球部——攻击/被击积累"热血ゲージ"，发动后全队攻防提升，超必杀时所有射门变一击必杀。River City Girls 2——绿色 SP 槽，攻击敌人回槽，重攻击长按释放必杀。热血行进曲マッハ——"怒り"状态，受到一定伤害进入怒气，期间属性/必杀强化。
  - 来源：https://www.kuniokun.jp/dodge/system/ ；https://www.kuniokun.jp/rcg2/system/

**体育化玩法**
- **【事实】** 热血足球必杀射门：接球后按角色固定步数带球跑动再射门即出个人专属必杀。典型必杀：ねんりきしゅーと（自由操控球轨迹）、もろはのしゅーと（会打反弹回来的队友/友伤）、ラストシュート（体力越低威力越强/残血爆发）、びりびりしゅーと（带电麻痹）、ゆーふぉーしゅーと（UFO 变形追踪）。核心乐趣：不漂亮传球，而是用铲球把人撞飞再射门的乱斗式体育。
  - 来源：https://wikiwiki.jp/nnnes1/熱血高校ドッジボール部_サッカー編 ；https://www.kuniokun.jp/dodge/charactor/

**角色属性与经济系统（热血物语 RPG 化）**
- **【事实】** 八维属性：ぱんち（拳攻）、きっく（脚攻）、ぶき（武器威力）、ちから（投掷/冲刺攻）、すばやさ（速度）、ぼうぎょ（格挡）、きりょく（根性）、たいりょく（HP）。初始 2000 円，打杂兵掉落约 50–70 円/人。**死亡惩罚：所持金减半，回到上一个商店街重启**。
  - 来源：https://w.atwiki.jp/aniwotawiki/pages/61166.html ；https://sho1go.com/fc-010/

**多人/友军伤害**
- **【事实】** 热血物语 2P 模式 A/B：A＝队友攻击可命中（同士讨有，随时变 vs）；B＝队友不受伤。热血格斗传说最多 4 人，7 种陷阱竞技场（瀑布、冷库、带电墙、传送带、消失桥）。热血行进曲マッハ 4 队分两组 2v2，受伤害带入下一回合。
  - 来源：《热血物语》说明书；https://obscurevideogames.com/2013/10/06/nekketsu-kakutou-densetsu-riki-kunio-review-nes/

**载具系统**
- **【事实】** SV-001 Metal Slug 主役小坦克：双联火神炮（无限弹药、任意方向）＋主炮炮弹（弹药有限、威力大）；可蹲伏打开舱盖让炮击从头顶过；耐久约 3 格。其他载具：Slug Copter（飞行 VTOL）、Slugnoid（二足全地形）、Drill Slug（钻地鼹）、Slug Mariner（潜水艇）。一辆 Slug 同时只能一人乘坐；受击后闪烁告警→必须立刻下车→否则爆炸。**乘降瞬间的无敌帧"鬼避け"是系列高级技巧**。
  - 来源：https://handwiki.org/wiki/Software:Metal_Slug ；https://game.snk-corp.co.jp/official/ms6/system/

**生命/续关/POW 救援**

### 2.3 对《热血物语：末日丧尸》系统设计的建议

**建议 1："热血近战 × 合金射击"用同一套伤害位打通**
- 借鉴 MS 伤害量级（手枪 10/近战 30/手雷 100），让不良少年的拳头/铁棍/投技伤害显著高于手枪、略低于重武器——贴脸群尸时必须用热血格斗清场，远处尸潮用枪
- 手持武器（铁棍）期间不能换弹/不能蹲（对应热血"持武器不能防御"的取舍）

**建议 2：必杀技做成"热血槽"，绑定丧尸题材做变身式高风险技**
- 融合热血"攻击/被击攒槽"与 MS3"僵尸化"：攒满热血槽放"马赫拳/旋风踢"等近战清屏技
- 反向地，被丧尸抓挠可触发半尸化——代价是变慢/锁武器，收益是吐出血腥高伤害喷射（致敬吐血激光），用"救急箱"解除

**建议 3：经济循环学《热血物语》**
- 打尸潮掉钱→黑市买技能/食物→死亡减半回档
- 花 3000 买"马赫踢"、花大钱买贵但未必强的大招（致敬"人間魚雷"贵而弱的反差喜剧）

**建议 4：载具用"不良改装车/改装坦克"包装**
- 把 SV-001 换成涂鸦暴走族战车/改装卡车：无限火神扫射＋有限主炮炮弹、3 格耐久闪烁后必须跳车
- 乘降瞬间无敌（鬼避け）作为高级操作技巧保留

**建议 5：多人合作保留"友军伤害 A/B 开关"**
- 默认开"同士讨有"模式——队友的铁棍、误射、甚至必杀都能打自己人
- 把救援 POW 改成"救幸存的路人/队友"，单关救够人数给巨额加分、任一人死亡本关救援数清零

```
热血物语：末日丧尸/
├── project.godot                  # 输入映射：move/jump/shoot/melee/switch_weapon
├── autoload/                      # 全局单例（参考 SurvivorsStarterKit）
│   ├── GameManager.gd             # 游戏状态机：menu/playing/wave_clear/gameover
│   ├── WaveManager.gd            # 尸潮波次：刷怪节奏、精英/Boss 生成、难度曲线
│   ├── BulletPool.gd              # 子弹对象池（参考 BlastBullets2D/PerfBullets）
│   ├── AudioManager.gd           # BGM/SE 总线分组、音量持久化
│   └── SaveManager.gd            # 关卡进度/武器解锁存档（参考 MetSys）
├── player/
│   ├── Player.tscn               # CharacterBody2D + 状态机
│   ├── player_controller.gd      # 移动/跳跃/crouch（合金弹头式趴躲）
│   ├── player_state_machine.gd   # 有限状态机：Idle/Run/Jump/Shoot/Melee/Hurt/Down
│   ├── weapons/                  # 武器为独立场景，可切换/拾取
│   │   ├── WeaponBase.gd
│   │   ├── pistol.tscn / shotgun.tscn / rifle.tscn / melee_fist.tscn
│   └── hurtbox.tscn
├── enemies/
│   ├── EnemyBase.tscn            # CharacterBody2D + AI 状态机
│   ├── enemy_ai.gd               # Chase/Attack/Hurt/Death（参考 arena-zoombie）
│   ├── zombie_walker.tscn / brute.tscn / spitter.tscn
│   └── boss/                     # Boss 多阶段 + 弹幕（参考 BulletUpHell）
├── combat/
│   ├── bullet.tscn               # Area2D 子弹，命中回调
│   ├── hitbox.gd / hurtbox.gd    # 碰撞层规范：玩家层/敌人层/子弹层/地形层
│   └── damage_system.gd          # 伤害数字/击退/爆头暴击
├── levels/
│   ├── Level_01.tscn             # 场景即关卡（TileMapLayer 拼接）
│   ├── wave_trigger_area.tscn    # 进入区域触发一波尸潮
│   └── parallax/                 # 横版视差背景
├── ui/
│   ├── HUD.tscn                  # 血条/弹药/武器图标/分数/波次提示
│   ├── main_menu.tscn / pause.tscn / gameover.tscn
│   └── damage_numbers.tscn
├── assets/ (art / audio / fonts)
└── addons/                       # 按需引入：BlastBullets2D / MetSys 等
```

**核心落地原则：**
1. **碰撞层规范先行**：hitbox（攻击）与 hurtbox（受击）分离，用图层掩码把"玩家子弹→敌人""敌人→玩家""近战拳→敌人"解耦
2. **子弹必走对象池**：不要每次 instantiate 子弹，用 BulletPool 复用节点
3. **玩家用显式有限状态机**：Idle/Run/Jump/Shoot/Melee/Hurt 分离，射击不锁死移动
4. **波次数据驱动**：WaveManager 用 Resource/配置表描述每波丧尸类型、数量、刷怪间隔
5. **热血手感**：g-orctober 的连击/击退/敌人围殴 AI 是近战参考，但需把 Godot 3.x API 迁到 4.x

## 4. 美术与动画风格

### 4.1 热血系列美术与动画风格

**角色设计：Q 版比例与不良少年视觉符号**
- **【事实】** 初代街机《热血硬派》（1986）采用偏写实成人比例；从《热血高校躲避球》（1987）开始全面切换为 **2.5～3 头身 SD Q 版小人**，此后 FC/SFC 作品固定。国夫君视觉符号：白色立领学兰服 + 黑鞋 + 飞机头（リーゼント/regent）。
  - 来源：https://www.kuniokun.jp/famicom/ttl-comment/ ；https://www.yystv.cn/p/10194
- **【观点】** Q 版比例的核心功能是表情可读性：2.5～3 头身让头部占比足够大，能在极小像素面积内绘制夸张面部表情（怒目、X 眼、哭脸），这是"搞笑打击感"的视觉基础。

**配色方案**
- **【事实】** 学校/队伍靠制服色区分（热血高校=白色学兰）。FC 时代整体偏暖校园/街道场景（建筑砖色、街道灰、天空蓝），角色高饱和制服色（白/黑/红）为视觉焦点。River City Girls（2019）配色升级：依赖平涂色块而非渲染阴影（flat colors and shapes rather than rendering and shading），呈现"波普艺术"风格。
  - 来源：https://www.nintendolife.com/news/2019/08/feature_wayforward_on_river_city_girls_its_crazy_interpretation_of_the_kunio-kun_brand
- **【观点】** 热血系列配色逻辑是"角色高饱和 + 场景中低饱和"：角色制服色在相对灰调的城市场景中跳出。

**动画帧数与节奏**
- **【事实】** FC 硬件限制下采用关键帧 + 有限循环策略：出拳/踢腿等攻击动作约 **3～5 帧**；行走/奔跑循环约 **4～6 帧**。表情帧是重点投入——从《热血物语》起"被攻击时露出各种夸张、搞笑的表情"成为系列标志。《热血格斗传说》中角色"在拳脚碰撞时以令人满足的重量拉伸和挤压"。
  - 来源：https://www.yystv.cn/p/10194
- **【观点】** FC 时代动画哲学不是"流畅"而是"关键 pose 强 + 表情夸张"：用最少帧数把攻击起始、命中、收势三个 pose 做夸张，中间帧能省则省。玩家感受到的"打击感"主要来自命中瞬间的表情切换 + 击退位移。

**打击反馈与搞笑演出**
- **【事实】** 受击表情系统：敌人被打时出现 X 眼、哭脸、怒目等夸张面部表情；敌人受击时画面下方弹出滑稽文字。角色被打飞时旋转倒地。RCG 升级：角色"ぬるぬる（丝滑）地动"，BOSS 战动画华丽；Arc System Works 参与 VFX 和夸张攻击动画指导，参考《Dragon Ball FighterZ》过场攻击演出。
  - 来源：https://www.nintendolife.com/news/2019/08/feature_wayforward_on_river_city_girls_its_crazy_interpretation_of_the_kunio-kun_brand

**现代重制版（RCG）美术升级方向**

| 维度 | FC 原版 | RCG 重制版 |
|---|---|---|
| 头身比 | 2.5～3 头身 | 约 3～4 头身 |
| 像素风格 | 8-bit 粗线条有限色板 | 16-bit 风格 + 平涂色块（非精细渲染） |
| 背景 | 简洁单层 | 多层视差 + 丰富细节 |
| 叙事表现 | 纯 sprite + 文字框 | 漫画分格 + 动画 CG + 动态漫画混合 |
| 动画流畅度 | 3～5 帧关键 pose | "ぬるぬる"丝滑动画，攻击参考街霸/摔跤 |
| VFX | 无 | 参考 DBFZ 的夸张攻击特效 |

- 关键设计决策（WayForward 导演 Adam Tierney 原话）："保留缩放后的像素画比直接跳到 2D HD 或 3D 更不突兀……他们的风格更依赖平涂色块和形状，而非渲染和阴影。"
  - 来源：https://www.nintendolife.com/news/2019/08/feature_wayforward_on_river_city_girls_its_crazy_interpretation_of_the_kunio-kun_brand

### 4.2 合金弹头美术与动画风格

**角色设计：Q 版军事小人**
- **【事实】** 主角 Marco/Tarma/Eri/Fio 均为 **约 2.5～3 头身 Q 版比例**。Neo Geo MVS 街机分辨率 320×224，角色 sprite 实际高度约 **30～40 像素**。角色 sprite 拆分为上半身/下半身两部分，可独立动画（下半身奔跑循环 + 上半身射击动作同时播放）。
  - 来源：https://citygame.com.ar/metal-slug-pixel-art/ ；https://linclogames.com/metal-slug-is-pixel-art-perfection/
- **【观点】** 合金弹头的 Q 版军事设计核心是"卡通比例 + 写实装备细节"：身体是 Q 版的，但枪械、军装、载具的结构细节和材质阴影按写实标准画，形成"玩具兵般的真实感"。

**配色方案**
- **【事实】** 军事主色调：橄榄绿、沙黄/卡其、铁灰、棕褐色。高饱和强调色：爆炸橙黄、火焰红、枪口焰白、子弹曳光色。叛军士兵有 2 组各 5 个不同色阶的阴影（按部位分组用色板，每组 5 色：高光→中间调→暗部）。
  - 来源：https://6th-divisions-den.com/ms_tutorial.html
- **【观点】** 配色逻辑是"背景沉静 + 动作元素炸裂"：军事场景压低饱和度让战场"可信"，但爆炸、火花、子弹等高饱和效果在灰色调背景中极度突出。

**动画帧数与节奏（核心数据）**
- **【事实】** 开发者 Akio Oyabu 确认，Metal Slug 2 仅角色动画就有约 **6000 帧**。同时代 run-and-gun 游戏主角通常 4～6 帧动画；合金弹头复杂动作用到**最多 16 帧**。仅跳跃就有约 6 帧。单个士兵有**近 20 种不同死亡演出**。动画设计上约 **28fps 有效动画帧率**手感最佳（"28 frames per second is what works"）。
  - 来源：https://shmuplations.com/metalslug2/ ；https://www.siliconera.com/snk-developers-talk-about-how-some-of-the-classic-arcade-games-were-made/
- **【事实】技术秘技——"亚像素动画"（sub-pixel animation）**：设计师 Tanaka 描述"只要偏一个像素，看起来就像下巴脱臼了……我们像在画 0.5 像素。方法是稍微改变周围像素的颜色，让人眼感觉像素移动了约 0.5 像素。"轮廓明暗法：肢体向前移动时轮廓线变亮、向后时变暗，不移动 sprite 位置就产生深度感。
  - 来源：https://www.siliconera.com/snk-developers-talk-about-how-some-of-the-classic-arcade-games-were-made/

**打击反馈与死亡演出**
- **【事实】** 命中粒子：枪口焰、子弹曳光、弹壳抛出（带重力）、命中火花、血液喷溅。多样化死亡：普通射击出血倒地、火焰喷射器人体火炬→烧灰、霰弹枪瞬间爆裂、电击抽搐僵直、爆炸炸飞多段、水中落水消失。敌人搞笑反应：惊慌逃跑、跪地求饶哭泣、举手投降、跳舞庆祝。载具破坏：受击冒烟→起火→多段爆炸解体。屏幕震动：爆炸/大威力武器命中时有镜头震动。
  - 来源：https://gaminghell.co.uk/MetalSlug.html
- **【观点】** 合金弹头打击反馈核心公式：命中火花（2～3 帧）→ 敌人变形/死亡多段动画（10～20 帧）→ 屏幕震动 + 粒子扩散。它不靠"闪白"而靠敌人自身丰富的死亡演出传达打击感。

**场景美术与视差滚动**
- **【事实】** 通常 **2～3 层背景**即可产生强烈纵深感——前景紧邻角色，中层（远处建筑/山脉），远景（天空/云）。几乎所有建筑/桥梁/哨塔都可被炸毁，碎片飞入前景。
  - 来源：https://linclogames.com/metal-slug-is-pixel-art-perfection/

**美术制作流程**
- **【事实】** Nazca Corporation（由 Irem 前员工十几人创立），核心设计师 Akio Oyabu（MAX D）。工作流程：首席设计师先做基础设定 → 其他 staff 添加实际动作和动画 pattern → 很多资产直接做成游戏内 asset 不画概念稿 → 原画在纸上绘制 → 通过 digitizer 扫描进电脑 → 在像素工具中修整 → 旋转帧全部手绘（Neo Geo 不支持硬件旋转）。制作哲学："越是只出现一次的东西，越要在动画帧上挥霍。"
  - 来源：https://shmuplations.com/metalslug2/ ；http://tvga.me/interviews/metal_slug_anthology/

### 4.3 对《热血物语：末日丧尸》美术与动画风格的建议

**建议 1：角色比例取"3～3.5 头身"中间值，用 2.5D 而非纯像素**
- 保留热血系列的飞机头/学兰/宽肩 silhouette 辨识度，但身体比例比 FC 版更修长
- 用 2.5D（3D 建模 + 卡通渲染/手绘贴图）而非纯像素画，避免直接复刻 16-bit 像素
- 飞机头 + 学兰立领 + 卷袖/解开领口等不良少年改装细节必须保留

**建议 2：动画密度学合金弹头，表情夸张学热血系列**
- 主角动作（奔跑/射击/近战/翻滚）走合金弹头路线——每个动作 8～15 帧流畅过渡，加入后坐力、手臂麻木、换弹等细节演出
- 受击反馈走热血路线——主角被丧尸抓挠时弹出夸张吐槽表情帧（怒目、咬牙、"喂！"字幕气泡）
- 丧尸死亡走合金弹头路线——多段式死亡动画（踉跄→扑倒→碎裂/倒地抽搐），不同武器对应不同死亡演出

**建议 3：配色采用"灰绿废墟底 + 高饱和动作强调色 + 主角白学兰跳出"**
- 场景：城市废墟/夜晚街道，主色灰绿/灰褐/暗紫
- 丧尸：腐绿/灰紫/暗褐
- 主角：白色学兰 + 红/黄点缀（围巾/书包带），在灰绿废墟中成为最亮视觉焦点
- 动作特效：爆炸/火焰/血花用高饱和橙黄红

**建议 4：打击反馈公式 = 合金弹头粒子 + 热血表情气泡**
- 命中瞬间：火花/血花粒子（2～3 帧）+ 屏幕微震（学合金弹头）
- 主角攻击命中后：短暂弹出吐槽表情 + 搞笑拟声词（学热血"BARF"式打击台词）
- 大威力终结技：慢动作 + 慢镜头血液飞溅 + 漫画式分格特写（学 RCG/DBFZ 式夸张演出）

**建议 5：场景做 2.5D 多层视差 + 可破坏环境，叙事用漫画分格穿插**
- 游戏内场景：2.5D 视差滚动（近景 1.0x、中景 0.3x、远景 0.05x），场景可破坏
- 关卡间剧情/BOSS 登场：切换为手绘漫画分格 + 夸张分镜（学 RCG），而非纯 3D 过场
- 场景主题：学校/商店街/天台/废旧工厂/体育场馆，融入丧尸爆发后的废墟改造

## 5. 氛围与叙事包装

### 5.1 合金弹头的军事幽默基调

**整体基调：严肃军事外壳 × 荒诞幽默内核**
- **【事实】** 合金弹头基调被描述为"骑在战争题材与卡通幽默的分界线上"：有坦克、士兵、机枪、战俘，但"并不写实，而是夸张、怪诞、近乎闹剧（slapstick）"。摩登军士兵"不是无脸靶子，而是会害怕、偷懒、恐慌的小人物喜剧角色"。初代基调被特别称为"黑色喜剧（dark comedy）"：既有坏结局、敌兵被肢解式的血腥处决，也有 Mission 3 里士兵把自己冲下马桶、Mission 5 里抱着猫瑟瑟发抖的老妇。
  - 来源：https://mchenryslair.com/2026/05/10/insert-coin-here-metal-slug-super-vehicle-001/ ；https://gaminghell.co.uk/MetalSlug5.html
- **【建议】** 基调公式："正经的世界观设定 + 不正经的演出与细节"。丧尸末日可以有严肃起因，但玩家接触到的几乎每一个单位、道具、过场都要带"人味"的小动作。

**幽默元素的具体表现**
- **【事实】** 敌方士兵"表情极其丰富"：会在玩家到来前互相说笑，玩家一到就尖叫；会瘫在折叠椅上喝东西、在小篝火前做饭；连武器（烟花、大雪球、抱石头砸坦克机枪）都像是临时凑出来的。"goofing-off 动画和暴力死亡动画一样多。"作曲家兼音效监督 Hyakuta 证实："游戏里有跟玩家无关的旁白，我想从战场发送一些信息。"幽默不仅在过场，"而在玩法本身：士兵惊慌、僵尸呕吐、外星人跳舞"。
  - 来源：https://gaminghell.co.uk/MetalSlug.html ；https://bitvint.com/pages/the-history-of-metal-slug
- **【建议】** 把"搞笑"做在待机与非战斗帧上，而不是做在叙事台词里。每个普通丧尸/敌人单位至少设计 2–3 个 idle 演出（发呆、偷吃、打瞌睡、内讧）。

**反派塑造：摩登将军——滑稽但有魅力的"恨不起来的反派"**
- **【事实】** 官方设定：前正规军将军唐纳德·摩登发动全球军事政变。悲情底色：摩登本是正规军海军中将、爱兵如子；2023 年一场恐怖袭击夺走他妻儿，调查后发现正规军高层本可避免却坐视不理，遂率部下反叛。2 代结尾摩登被火星人调包，3 代里反派军与主角联手救摩登、打火星人——"被我们追着打的 Boss 其实一直在默默拯救地球"。
  - 来源：https://www.metalslug10th.com/english/history/series11/index.php ；https://news.qq.com/rain/a/20211119A0A96400
- **【建议】** 主反派不要做纯恶，而做"有悲壮理由的魅力型头目"。设计"反派部下对其极度忠诚"的细节（小兵愿为他送死、为他修装备），这比任何洗白台词都有效。

**人质（POW）系统的喜剧效果**
- **【事实】** 被救 POW 是"系列最受欢迎也最奇怪的元素之一"：满脸胡茬、仅穿破烂短裤的战俘散落在各关；解放后他会敬礼、给"喜剧式礼物"（武器箱/食物/加分），随即激动得抽搐般狂奔出屏。那句"Thank you!"是系列名梗。2 代里藏着一个被救后不逃走、跟在主角身边用"波动拳"打敌人的超强老头。
  - 来源：https://maisplay.com/curiosidades-serie-metal-slug/ ；https://wap.gamersky.com/news/content-785092.html

**音乐与音效**
- **【事实】** 作曲/音效监督为 Takushi Hiyamuta（HIYA!）。他用有限合成器做出"重金属 + 爵士 + 军国管弦乐"的杂糅，自称受《雷鸟特攻队》、Emerson Lake & Palmer 前卫摇滚、《星球大战》启发，偏爱萨克斯。系列主曲"以英雄旋律与军乐配器为主，完美契合夸张场面，又穿插更深沉的爵士间奏"。
  - 来源：https://bitvint.com/pages/the-history-of-metal-slug ；http://www.vgmonline.net/metalslugbox/
- **【建议】** 把"进行曲/军鼓/铜管号角"当成幽默的正经伴奏——越一本正经的军乐，配越滑稽的战场，反差越搞笑。

**各代基调变化曲线**
- **【事实】** 1 代偏严肃、暗调黑色喜剧；2 代引入外星人；**3 代被公认为"从略疯到彻底疯狂"的转折点**，引入分支路线、巨型螃蟹、邪恶克隆人、僵尸、木乃伊、海底异形、最终太空决战，被多家称为"系列巅峰/最荒诞一作"。
  - 来源：https://www.honestgamers.com/5610/wii/metal-slug-anthology/review.html ；https://vectree.io/c/metal-slug-3

### 5.2 热血系列的校园不良基调

**世界观与基调**
- **【事实】** 系列 1986 年以"正义的不良少年"为主题在街机问世，被称为清版动作（Beat 'em up）鼻祖；制作人岸本良久本人高中就是不良/暴走族，结合自身经历做企划。系列分两大支：《硬派》线偏严肃、人物用偏大头身比例；《DownTown（DT/River City）》线偏轻松，用 2.5–3 头身 SD 小人 + 夸张逗趣表情。
  - 来源：https://www.yystv.cn/p/10194
- **【建议】** 《热血物语：末日丧尸》视觉与基调应对齐 DT/SD 闹剧线（而非严肃的硬派线）。严肃感只放在"兄弟情义"的情感锚点上。

**核心角色塑造**
- **【事实】** 国夫（くにお）：热血高校番长，"正义的不良"，讨厌歪门邪道与欺负弱小；为朋友两肋插刀；运动万能；得意必杀"马赫踢"；性格上"得意忘形、有点好色"。阿力（りき/Riki）：花园高校番长，国夫的宿敌兼好友；比国夫更快出拳的"马赫拳"。
  - 来源：https://www.kuniokun.jp/nekketsusp/en/chara/ ；https://w.atwiki.jp/gcmatome/pages/3241.amp
- **【建议】** 主角团照"双主角宿敌→并肩"模型：一个"热血一根筋 + 好色 + 必杀一脚"型，一个"冷静/毒舌 + 出拳更快"型。性格必须带"小缺点"，不要做完美主角。

**校园/不良文化符号（美术与世界观取材清单）**
- **【事实】** 学兰（学ラン/诘襟）：日本男子校服，立领、黑色为主、五粒校金扣，源自海军/普鲁士制服；不良会改造成长兰/中兰/短兰。ヤンキー造型：飞机头（Regent）、烫发（Punch Perm）、染棕发；极宽大腿窄脚的"ボンタン"裤；外套特攻服（tokkofuku），胸口后背绣"天下无双""义理人情"等大字。女番长符号：把校服裙刻意改长（藏球棒/铁链/剃刀）。
  - 来源：https://zh.moegirl.org.cn/学兰 ；https://www.fun-japan.jp/en/articles/14558

**各作场景与主题（关卡题材参考库）**
- **【事实】** 热血硬派：车站、黑道内部；初代热血硬派（SFC）：毕业旅行去大阪，穿梭大阪街道、买自动贩卖机饮料、搭电车移动；热血物语：转校生龙一龙二兄弟引发街头大战；热血足球：足球部食物中毒无法参赛，国夫率躲避球部顶替出战；热血格斗传说：国夫在鞋柜发现挑战书，神秘人办"格斗大会"。
  - 来源：https://www.kuniokun.jp/technos_world/zh-hans/ ；https://www.yystv.cn/p/10194
- **【建议】** 关卡可借用"日常空间被事件扭曲"的题材：鞋柜区（开局异变）、天台、体育馆/篮球场、商业街（自动贩卖机当补给点）、电车站、暴走族聚集地。

**音乐风格**
- **【事实】** FC/SFC 时代原声由 Technos 作曲家（泽和雄 Kazuo Sawa 等）操刀，8-bit 合成器；《热血物语》配乐"在当时革命性，旋律与合成器的复杂编排"被粉丝视为系列巅峰。
  - 来源：http://www.vgmonline.net/kuniocassette/ ；https://vgmdb.net/album/10400
- **【建议】** 8-bit/chiptune 风格的"激昂、奔跑感"旋律线——节奏快、鼓点密、铜管式合成器音色做主角。

**现代重制版（RCG）的基调演变**
- **【事实】** WayForward 受 Arc System Works 监督制作（2019），方向是"goofy, zany direction"（搞笑、脱线方向）；把传统主角国夫/阿力变成"被绑架的弱男"，由其女友美佐子、京子闯城救人。约 50 个有台词角色，大量致敬旧作；过场由 Studio Yotta + 漫画分镜插画风；音乐"epic synth-pop"，62 首（约 9 首人声曲）。系统创新："招募（recruits）系统"——把房间敌人打到只剩一个、打残后它会求饶，玩家可选择不杀、收为"援护攻击"。
  - 来源：https://www.nintendolife.com/news/2019/08/feature_wayforward_on_river_city_girls_its_crazy_interpretation_of_the_kunio-kun_brand

### 5.3 融合方向建议

**C1. 世界观与叙事基调**
- 采用合金弹头式"正经设定 + 不正经演出"骨架，但把"军事"层替换为"不良少年街头"层
- 恐怖感只做"脉冲"，不做"底色"：每隔几关放一段短暂的"真紧张"（夜路、停电），马上用搞笑单位/梗泄压
- 情感锚点放在"兄弟情义"：剧情煽情只用于"为朋友/同伴拼命"，其余全是搞笑

**C2. 叙事结构与反派**
- 主反派走摩登路线："有悲壮理由、部下极度忠诚"的魅力型头目（某暴走族总长/学生会会长，因学校/街区被体制放弃而与丧尸源头势力勾结，后期与主角联手打真正的幕后黑手）
- "自己人也能打、打完又联手"：1–2 个敌对帮派在中期因共同敌人变成友军

**C3. 敌人/丧尸的搞笑化处理（核心可操作清单）**
- 每只普通丧尸 2–3 个 idle 演出：在自动贩卖机前发呆、偷吃掉落的零食、对着碎镜子整理发型、两只丧尸为抢一个书包互殴、打瞌睡被主角踩醒
- 受击喜剧：学热血 SD——被打飞时拉长变形、撞墙弹回、撞进垃圾桶只露两条腿
- 变异机制（参考合金 3 代）：被丧尸特殊攻击打中会临时变异（变慢/变大/获得搞笑强力技）
- 收服系统（直接移植 RCG recruits）：把特殊精英丧尸/敌对杂兵打残→求饶姿势→玩家选择"收了它"→变成关卡内援护召唤物

**C4. 场景氛围**
- 逐关把"日常→灾变"：鞋柜/教室（开局异变）→ 天台/体育馆 → 商业街（霓虹灯+丧尸夜景反差）→ 电车站/地下通道（短暂真紧张）→ 暴走族聚集地/工厂后门（Boss 关）
- 色彩节奏：明亮校园关（暖黄）→ 商业街夜景（霓虹紫蓝）→ 工厂终局（冷绿/锈橙）

**C5. 音乐风格融合（可直接给作曲的 brief）**
- 主线：热血 8-bit/chiptune 的"快、燃、奔跑感旋律" + 合金弹头式"军鼓滚奏 + 铜管号角进行曲式配器"——用 chiptune 音色做主旋律，军鼓/铜管做正经伴奏
- 错位幽默：越荒诞的战场，越配一本正经的进行曲
- 名场面人声突袭（学 RCG）：Boss 战前/通关结算突然插入带人声的燃曲
- 音乐彩蛋：每关结尾播放风格化"过关进行曲"

## 6. 综合设计建议汇总

> 以下为跨 5 个主题的核心建议提炼，按优先级排列。

### 第一优先：UI 与视觉语言
1. **HUD 融合布局**：顶部信息带（得分/残机/时间，学合金弹头）+ 左下角弹药+手雷双数字（学合金弹头）+ 左上角体力槽（学热血物语顶部横条）+ 右上角金钱/点数
2. **离散头像式生命条**：5–7 个不良少年头像图标，受击变暗/破碎，回复道具用街头零食（饭团/泡面/运动饮料）
3. **"热血魂"SP 槽**：攻击/被击/连击积攒，满槽放必杀，充能时颜色灰→黄→红渐变 + 屏幕边缘泛红光
4. **视觉语言锁定**：12–16 色调色板（热血红/蓝/黄 + 丧尸绿），粗体方块像素字体 + 等宽数字，像素硬边矩形边框无圆角无渐变
5. **商店两层菜单 + 中央预览动画**：左列分类 + 右列商品列表，选中时中央弹出武器动画预览

### 第二优先：系统与玩法
6. **伤害位打通**：拳头/铁棍伤害 > 手枪 < 重武器，贴脸用格斗、远处用枪；手持武器期间不能换弹/不能蹲
7. **半尸化变身机制**：被丧尸抓挠触发，变慢/锁武器但获得高伤害血腥喷射（致敬 MS3 吐血激光），救急箱解除
8. **热血经济循环**：打尸潮掉钱→黑市买技能/食物→死亡减半回档；贵但未必强的大招（致敬"人間魚雷"）
9. **不良改装车载具**：无限火神 + 有限主炮，3 格耐久，乘降无敌帧（鬼避け）
10. **友军伤害开关 + 路人营救系统**：默认开同士讨，救幸存路人给加分，阵亡清零

### 第三优先：美术与动画
11. **3～3.5 头身 2.5D 角色**：保留飞机头/学兰/宽肩 silhouette，用卡通渲染而非纯像素
12. **动画密度合金化 + 表情热血化**：主角动作 8–15 帧流畅过渡（学合金弹头），受击时弹出夸张吐槽表情（学热血）
13. **配色：灰绿废墟底 + 白学兰主角跳出 + 高饱和动作特效**
14. **打击反馈 = 合金粒子 + 热血表情气泡**：命中火花+屏幕微震 + 吐槽表情+搞笑拟声词
15. **2.5D 多层视差 + 可破坏环境 + 漫画分格叙事**

### 第四优先：氛围与包装
16. **基调公式**：正经设定 + 不正经演出；恐怖感只做脉冲不做底色；情感锚点在兄弟情义
17. **魅力型反派**：有悲壮理由 + 部下极度忠诚，中期与主角联手
18. **丧尸搞笑化**：每只普通丧尸 2–3 个 idle 演出（发呆/偷吃/互殴），受击拉长变形/撞垃圾桶
19. **收服系统**：打残精英丧尸→求饶→收为援护召唤物（移植 RCG recruits）
20. **音乐融合**：8-bit chiptune 主旋律 + 军鼓/铜管进行曲伴奏；越荒诞越配正经军乐；Boss 战前插入人声燃曲

### 工程落地
21. **优先精读 3 个开源项目**：SurvivorsStarterKit（波次/Boss）→ comedot（组件化架构）→ godot-blast-bullets-2d（子弹池性能）
22. **项目架构**：autoload 单例（Game/Wave/BulletPool/Audio/Save）+ 玩家有限状态机 + hitbox/hurtbox 碰撞层分离 + 波次数据驱动
23. **子弹必走对象池**，不要每次 instantiate
