### 3.4 伤害计算流程（推断）

根据方法名和调用关系，伤害计算的调用链如下：

```
攻击者发起攻击 (CAttackCollision.HitFunc)
  │
  ├─ 1. 从 mstAttackCollisionData 读取基础 damage 字段
  │
  ├─ 2. CDamageCalculator.CalcDealtDamage()
  │     ├─ 读取攻击者攻击力 (PARAM.PUNCH / KICK / WEAPON / THROW)
  │     ├─ 读取武器攻击力 (GetWeaponPower)
  │     ├─ Buff_Mul() / Buff_Add() 应用 buff 修正
  │     └─ 输出基础伤害值
  │
  ├─ 3. CDamageCalculator.CalcCritical()
  │     ├─ 掷骰 < m_Critical (攻击者暴击率) ?
  │     └─ 是 → CalcCriticalDamage() 从 m_CriticalDamageArray 取倍率
  │
  ├─ 4. CDamageCalculator.CalcMagnificateDamage()
  │     └─ 应用伤害放大技能（DAMAGE_SKILL 类型）
  │
  ├─ 5. CDamageCalculator.CalcFinalDamage()
  │     ├─ 减去防御方 Tough（韧性）减免
  │     ├─ 应用 ResDown/ResStun/ResBreak 抗性
  │     ├─ 应用 MaxDamage 上限
  │     └─ 输出最终伤害值
  │
  └─ 6. CDamageActionControl.Hit()
        ├─ 扣 HP
        ├─ 累积 DownValue / StanValue / BreakValue
        ├─ 触发受击动画 (EnumAction.Body_Damage_S/M/L 等)
        └─ 触发击退 (Futtobi 系列)
```

**关键推断：**
- **防御减免**：存在（通过 `TOUGH` 参数 + `RES_DOWN/STUN/BREAK` 抗性）
- **暴击**：存在（`CalcCritical` + `m_CriticalDamageArray` 倍率表）
- **属性克制**：DLL 中未见明显的属性克制表，攻击类型由 `damagetype` 字段区分（HP/SP/MONEY）
- **伤害上限**：`m_MaxDamage` 字段防止单次伤害过高
- **根性系统**：`m_GutsHpRate` — 残血时保命机制

### 6.2 连击窗口

从 `EnumActionCommmon` 枚举中发现：

| 枚举值 | 说明 |
|--------|------|
| `PUNCH_COMB_INIT` | 拳连击初始段数 |
| `PUNCH_COMB_MAX` | 拳连击最大段数 |
| `KICK_COMB_INIT` | 脚连击初始段数 |
| `KICK_COMB_MAX` | 脚连击最大段数 |

**结论：**
- **拳连击**：有独立计数器（`m_PunchComboControl`），初始/最大段数由数据表 `mstActionCommonData` 配置
- **脚连击**：有独立计数器（`m_KickComboControl`）
- **连击窗口**：`CComboCountController.DELAY_LIMIT` 控制连击计数的持续时间
- **交替加成**：CActorComboControl 同时维护拳和脚两个计数器，拳3段+脚2段的交替组合可能由此实现

## 核心结论摘要

1. **参数驱动方式**：数据表（`mstActorParamaterData`）+ 运行时叠加（`CActorParameter.RecalcLastStatus()`），非纯硬编码
2. **伤害公式**：`CalcDealtDamage` → `CalcCritical` → `CalcMagnificateDamage` → `CalcFinalDamage`，含暴击、防御减免、buff 修正、伤害上限
3. **EnumAction 规模**：**839 个动作状态**，远超 Godot 当前的 8 个状态。核心战斗状态集中在 0~388（基础+攻击），9000+ 为 SP/EX/事件扩展
4. **连击系统**：双计数器设计（拳 `m_PunchComboControl` + 脚 `m_KickComboControl`），交替加成天然支持
5. **蓄力攻击**：存在（Tame_Punch 三段：起手/蓄力/释放），有 SP 蓄力 UI
6. **格挡**：完整（Start→Guard→Hit/Break），有反击机制（SP_Counter）
7. **起身**：有 4 种起身方式（GetUp / GetUp_Roll / Down_Roll / Down_Roll_Back），根性起身（Reversal）存在
8. **Godot 移植优先级**：
   - **第一优先**：倒地/起身系统、格挡、蓄力攻击（当前完全缺失）
   - **第二优先**：连击交替加成、SP 槽、暴击
   - **第三优先**：合体技、半尸化、状态效果（复杂系统）
