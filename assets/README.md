# 美术与音频资源

当前原型阶段使用代码内色块占位（ColorRect），尚无真实美术资源。

## 规划方向（情报汇总后更新）

- 主角：热血不良少年，现代像素/手绘混合风格
- 丧尸：三种类型（步行 / 疾跑 / 胖子），可辨识的剪影配色
- 场景：街道、校园、屋顶，2.5D 视差背景
- UI：见项目规划书（基于热血系列与合金弹头 UI 情报设计）

## 素材来源约定

- 所有美术与音频均为原创或使用免费可商用素材（如 Kenney、OpenGameArt）
- 不复制热血系列 / 合金弹头 / 其他商业游戏的原画、角色与音乐

## 目录预留

```
assets/
├── sprites/   # 角色与丧尸精灵图
├── tiles/     # 场景瓦片
├── ui/        # 界面元素
├── audio/     # 音效与音乐
└── fonts/     # 字体
```
